TrackHire - Job Application Tracker

Project Overview
Build a full-stack MERN application called TrackHire, a centralized platform that helps job seekers manage their entire job search process.
The application allows users to:
●	Track every job application
●	Monitor interview stages
●	Store recruiter details
●	Manage multiple resume versions
●	Schedule interviews
●	Receive reminders
●	View analytics
●	Search and filter applications
●	Generate insights about their job search
The application should be production-ready, scalable, and follow clean architecture principles.
